# Our Free Model 2.5.9

## Plugin Update

This version releases the DSH plugin, including the clean-up and fixes merged into the mainline since 2.5.8:

- Removed an account channel that is no longer offered, together with its login, OAuth, models, credits, request signing and dedicated RPCs; the implementation and page entries are cleaned up together. The other 10 account channels, the anonymous free lane and EAC are kept.
- Extracted the browser opener and rate-limiting tools still used by other channels, and removed idle dependencies; the original open-source copyright and author attribution are kept.
- Regenerated the plugin channel pack and the standalone service channel resources; desktop packaging now includes only the files in the resource manifest, and expired frontend resources are deleted at build time.
- Shared storage and backups use neutral naming; legacy preferences, locks, statistics and valid backups remain readable and importable.
- The channel descriptions in the Chinese and English and standalone READMEs were updated in sync, and community group 5's QR code and group number `1128964440` were updated.

The standalone service and desktop shell versions remain unchanged, and no new Windows desktop installer is released this time. Tag-triggered macOS community builds are handled separately by the existing CI.

## Installation

The plugin package is `dsh-our-free-model-2.5.9.tgz`. For a hosted install, update the trusted tarball path in the profile, then let the host re-resolve the dependencies; for a self-managed install, update through the plugin upgrade page.

## Verification Boundaries

Before release, the plugin channel mounting, historical storage and backup compatibility, generated-resource consistency, and the byte integrity of the signed manifest and installer package are checked. Real upstream account calls and Windows/macOS installer installation are outside this acceptance scope; this version does not promise to lift upstream client, region or quota restrictions.

## Rollback

Restore the trusted `2.5.8` plugin tarball and re-resolve following the host installation flow. User configuration, accounts and statistics are kept.
