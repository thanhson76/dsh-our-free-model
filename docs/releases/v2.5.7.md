# Our Free Model 2.5.7

## Plugin Update

This version releases the DSH plugin, based on PR #481, already merged into main, and includes the mainline fixes since 2.5.6:

The standalone service and desktop shell versions remain unchanged, and no new Windows desktop installer is released this time. Tag-triggered macOS community builds are handled separately by the existing CI.

## Installation

The plugin package is `dsh-our-free-model-2.5.7.tgz`. For a hosted install, update the trusted tarball path in the profile, then let the host re-resolve the dependencies; for a self-managed install, follow the existing plugin update flow.

No user configuration, accounts or statistics need to be migrated. Manual speed-test results are stored separately and do not modify the existing probing record structure.
