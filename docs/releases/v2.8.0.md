# v2.8.0 Plugin Release

This release is DSH-plugin only; the desktop installer and standalone product versions remain as they were. Both mainline changes sit in the "keep up with upstream" layer
of the free lane and the bundled engine: the anonymous free lane's request shaping is wholly replaced by a file-by-file JS port of the reference gateway opencode2api v1.4.6,
and the bundled Magpie engine follows from c551a22 of 10-23 to 6a900e0d of 10-31 — and from now on following it is a single command.

## Anonymous Free Lane: the Shaping Layer Ports opencode2api v1.4.6

- **All client tools go on the wire renamed**: every caller tool is renamed to an opaque `clint_<sha256[:12]>` wire name
  (`tool_choice`, historical tool_calls / tool_use / function_call, and the call lines in a Responses `input` are renamed in sync,
  and folded back on the response side), so a foreign client's tool vocabulary no longer goes on the wire at all — measured on 2026-10-30,
  `ReportFindings`/`ScheduleWakeup` appearing together meant an immediate 429; renaming is the generalised form of that two-alias table.
- **The official 13-tool set is declared in full**: the definitions are taken word for word from capture files of the official 2.1 CLI (the chat wire carries
  `strict: false`, and the Windows host shell description says powershell); a declaration already carrying a word-for-word official definition is treated as
  an official declaration, and repeated shaping is idempotent.
- **The official CLI system prompt is injected in full**: base prompt + `<env>` + the built-in skills, prepended line by line, with the caller's
  block objects and `cache_control` kept as-is; a request body already carrying the marker is skipped.
- **One 40-hex `x-opencode-project` per request**: quota is accounted per project × egress, and a shared `global` bucket
  is inherently exhausted; a literal `global` or a 40-hex commit given by the caller passes straight through.
- **Endpoints follow the 2.1 client's family paths**: `/inference/openai/v1/…`,
  `/inference/anthropic/v1/messages?beta=true`; the Messages wire gains the `anthropic-beta` header.
- **Session minting runs on a slow clock**: today's UTC midnight minus a hash offset of ≤30 days (a process salt), so a session's date always lands
  within the window upstream accepts; a persisted old id is re-minted as soon as its date falls out of the window, and one conversation still pins one session.
- The Chat body gains the official client's two constant fields: streaming `stream_options.include_usage: true`,
  and, when there is no cap, `max_completion_tokens: 32000`; the fallback clearing of `tool_choice: 'none'` is kept.
- The port is a pure-function directory, `src/o2a/` (the file mapping table and the seven intentional deviations are in its `SYNC.md`); the release form is still
  a single-file bundle, and the 80-file budget is unchanged.

## Bundled Magpie Engine Follows to 6a900e0d (2026-10-31)

- The engine is rebuilt pinned to upstream 6a900e0d, and the build flags change to the upstream release's own `-s -w`: the binary
  goes 68.6 MB → 64.8 MB and the gzip payload 45.3 MB → 27.2 MB, and **77 files** bring it back within the legacy upgrader's 80-file limit
  (without trimming it would need 81, exactly the number the real 1.3.1/2.5.9 reject).
- Added `npm run update:magpie` (`scripts/update-magpie-engine.mjs`): it resolves the target revision,
  moves the single pin, rebuilds, refreshes the shards and the bundle, and only counts as done once six contract suites have run; on failure it automatically rolls the pin and
  the engine state back to before the run.
- One narrow-panel fix in the engine UI: the 76px numeric input of "Long conversations · Compact at" (#876) in the settings list
  was cut in half on a 320px narrow panel; it gains the same shrink-and-wrap as upstream's agent prefs.
- The preset assertions of the plugin/native suites are unfrozen to the current upstream (59 built-in, 14 zoned, 64 zones), and the revision assertions
  now read `engine.json`, so the next engine update no longer needs test changes.

## Co-paid Channel Model Cards Re-checked Against the NVIDIA Build Pages

- The windows, vision and thinking levels of DeepSeek V4.1 Flash / GLM 5.3 Flash / the newly added Mistral Large 4 1T A52B are re-checked
  against their respective NVIDIA Build model pages and chat schemas: the level enumeration takes the platform's validated set
  (`none|minimal|low|medium|high|xhigh|max`), and Mistral has only the two levels Off/High (High by default).
- The cards of the free lane's two ids now display under the high-speed channel's highspeed names (`deepseek-v4.1-flash-highspeed
  1017` / `glm-5.3-flash-highspeed`); the catalog id does not move and routing is unaffected.

## Tests and Guards

- `npm test` adds the `legacy-payload` suite (`build-legacy-payload.mjs --check`): the release
  bundle (token-saver / o2a / core) and the engine shards must match the source, so changing `src/o2a/` and forgetting to repackage
  goes red in the tests on the spot instead of silently testing old code.
- The fingerprint / wire-shape / alias / alignment suites are all rewritten as behavioural assertions for the o2a port; the standalone mock follows the family paths and
  the 2.1.1 UA.

## Installation and Verification

Before release, the full release suite passed (110/110): production signing, the legacy upgrade regressions against the original 1.3.1 and 2.5.9,
generated-artefact consistency checks, and catalogue-record and byte consistency checks. The release tarball is built from the LF bytes of a pinned commit,
the runtime files match the formal signed manifest byte for byte, and the entry point loads after unpacking. After release, fetch verification of the default
update sources was completed as an installed user (live-audit), and the CDN was refreshed over the whole tree.

Real-machine clearance verification of the free lane's wire shape is limited by this machine's egress quota: the authoritative reference (a locally built and run opencode2api
v1.4.6 reference gateway) received exactly the same `FreeUsageLimitError` at the same egress and the same moment, proving that 429 is
an egress-quota matter rather than a porting defect; once the quota resets, `scripts/oc-free-live-test.mjs --live` can close it in one pass.

Self-installed legacy users can check for updates on the plugin upgrade page; host-managed installs should update the trusted
tarball through the original installation method; for a manual install, use this release's full plugin package and keep the original user data directory — do not replace only the entry files. The tests only
access local services and do not mean every network environment or real model upstream has been verified.

## Rollback

The upgrader continues to perform the original signature, file-size, SHA-256, backup and rollback checks. For a manual rollback, use the previous version's trusted
plugin package (v2.7.4), and keep configuration, accounts and statistics.
