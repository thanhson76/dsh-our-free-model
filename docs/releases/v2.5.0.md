# Our Free Model 2.5.0

## What's New

- **Fixed 403s across the whole free lane.** On 2026-10-17 upstream added **encoding validation** to session ids, no longer looking only at
  the `ses_` shape: the twelve hex digits must be the official client's **descending timestamp**
  (`~(milliseconds << 12 | counter)`, counter 1–63, with the low twelve bits landing in `0xfc0–0xfff`). The ascending form
  (`milliseconds << 12`) or any hash digest, even with a perfectly correct `ses_` shape, gets `403 FreeTierError` across the board.
  - The plugin now validates session ids by encoding: it adds `SESSION_DESCENDING_RE` and `isCanonicalSession()`;
  - A **non-descending** session id passed in by the caller is no longer passed through as-is, but is deterministically re-encoded into a compliant shape
    (`canonicalizeSession()`, so the same conversation still corresponds to the same upstream session).
  - Measured (same egress IP, same moment): original ascending id → 403, after re-encoding → 200, newly minted id → 200.
  - The session section of `scripts/free-lane-wire-test.mjs` is changed to assert the real encoding window, and a check that "an ascending
    id is re-encoded" is added.
- **The Recommended projects page adds a third project: EAC-design-world** (`Ebony-Vinyl/EAC-design-world`). It is
  a local video-production and design plugin for DeepSeek Harness — multi-track editing, templates and design systems, a native preview canvas,
  and real file export, with the whole flow completed on the local machine. Its Star / Fork / most-recent-commit counts are likewise fetched live from GitHub.
  The recommended-projects announcement names these three repositories in sync: whatever the page renders is what the announcement says.
- The plugin, the standalone local service and the Windows desktop shell are all upgraded to 2.5.0.

## Server Side (EAC Free Lane, Not Plugin Content)

The EAC channel's `deepseek-v4.1-flash-free` and `glm-5.3-flash-free` now go through the server-side
OpenCode anonymous lane gateway, with egress rotated through a **free proxy pool**, so per-IP rate limiting no longer affects availability. This part
is not distributed with the plugin and is noted here only for explanation.

## Upgrade and Restart

### DSH Plugin

Check for and install 2.5.0 under Settings → Plugin upgrade. End any requests still generating before upgrading; after installation, fully exit
DSH desktop (including the tray) and restart it, then confirm the version number and the free model catalogue.

### Standalone Local Service

Stop the old service first and back up the program directory and data directory, then replace the program files. Start the new version with the original data directory,
sign in through the management link printed at startup, and confirm the page shows 2.5.0. Do not run two instances sharing one data directory at the same time.

### Windows Desktop App

Choose "Exit" from the tray menu, then install the new full installer (`Our.Free.Model_2.5.0_x64-setup.exe`),
and reopen the app. Do not copy just the executable; the installer includes the standalone service and runtime resources.

### macOS Desktop App

No macOS installer was built this time (the build machine is Windows). macOS ARM64 users should keep using the v2.3.0 DMG,
or use the standalone local service CLI directly; this version's free lane fix applies to the standalone service as well.

## Data and Rollback

The upgrade keeps the existing configuration, accounts and statistics. The session mapping file `session-map.json` may hold non-descending ids written by an old version:
when the new version reads one it does not use it directly, but re-encodes it (the encoding is determined by the conversation seed, so it remains stable).
Rolling back to 2.4.0 does not affect user data; the old version will run into 403s again once encoding validation is in effect, as expected.
