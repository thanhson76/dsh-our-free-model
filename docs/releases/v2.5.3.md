# Our Free Model 2.5.3

An urgent fix for the EAC no-valid-output wait limit added in 2.5.2.

## Fixes

- Removed the rule that terminated an EAC request after 60 consecutive seconds with no body, thinking or tool increments, so that rule no longer produces `NO_PROGRESS`.
- Queueing, silent thinking, heartbeat-only or usage-only frames, and silent gaps after body output no longer trigger this deadline.
- The `progressTimeoutMs` in an old configuration no longer takes effect. A user cancellation still closes the upstream request; the existing transport disconnect detection and overall recovery time limit keep their original behaviour.
- No changes to OpenCode request headers, session encoding, tool declarations, the model catalogue or vendor admission logic.
- Fixed self-upgrading, when installing from a local development directory, also copying the `packages/desktop/src-tauri/target` build cache into the rollback directory and filling the system disk. The standalone product source and caches under `packages` do not take part in plugin backup and clean-up; the original files are kept.

## Installation and Update

The DSH plugin uses this Release's `dsh-our-free-model-2.5.3.tgz`. For a package-manager-hosted install, update the tarball path in the profile and re-resolve the dependencies through the host; the npm package of the same name is not published by this repository.

For Windows desktop, fully exit the old program in the tray, then run `Our.Free.Model_2.5.3_x64-setup.exe`. Configuration, accounts and statistics are kept. The installer is not Authenticode-signed.

The checksum file and release acceptance record are provided with the artefacts.

## Availability

This fix does not mean the anonymous OpenCode `403 / FreeTierError / LANE_LOCKED` has recovered, and it does not mark genuinely rejected models as available. Vendor network, authorization and quota will still affect inference results.
