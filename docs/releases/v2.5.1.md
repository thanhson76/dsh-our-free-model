# Our Free Model 2.5.1

## What's New

- **Fixed upgrade failures: added a manifest mirror reachable from China.** On some networks `raw.githubusercontent.com`
  and `cdn.jsdelivr.net` are very slow or intermittently unreachable (measured: a single `raw` request took 16.6 seconds, often hitting the 15-second
  budget and timing out; jsDelivr took about 11 seconds with occasional stream breaks), causing "Check for updates" to report
  `no manifest source answered` directly. Both paths now add a
  `raw.githubusercontent.com` proxy mirror (measured at about 1.3 seconds returning the same bytes):
  - Upgrade manifest: `raw` → `cdn.jsdelivr` → **mirror** → `master` fallback;
  - Announcement feed: the mirror is likewise added, so the splash announcement can be fetched on slow networks too.
  - The mirror does **not** fetch from a mutable branch: like the direct sources, it first resolves to a full commit SHA, then fetches
    the manifest and each file by SHA; signature and per-file SHA-256 verification run as usual, and the mirror itself is not trusted.
    The new `updater-test` assertions bring the mirror source into the "pinned to a commit SHA, no branch installs" group of
    checks.
- **Fixed the `org/` prefix showing in the small print on EAC cards.** Keeping the `org/` prefix in an EAC row's `id` is necessary —
  the free lane has a model of the same name (the bare name `deepseek-v4.1-flash-free`), and merging de-duplicates by id, so the prefix is exactly
  what stops the EAC row being displaced by the free lane; but the prefix is only a routing detail and should not appear on the card. Now
  the card's small print shows the model's own id (`deepseek-v4.1-flash-free`), while the name row still shows
  `EAC DeepSeek V4.1 Flash Free`.
- The server-side EAC channel's external model names are changed back to the `opencode/...` prefix (with a channel mapping pointing back to the upstream bare names),
  so the plugin's pinning, its `NEW` / "hot" badges, its "high-speed" label, the 1M context and the thinking levels all take effect.

## Upgrade and Restart

### DSH Plugin

Check for and install 2.5.1 under Settings → Plugin upgrade. If on the current network neither `raw.githubusercontent.com` nor
`cdn.jsdelivr.net` is reachable, the mirror source added this time takes over within the same check, with no extra configuration.

### Standalone Local Service / Windows Desktop App

As in the 2.5.0 notes: exit the tray program first, then start the new version with the original data directory or install the new full installer.

## Data and Rollback

The upgrade keeps the existing configuration, accounts and statistics. Rolling back to 2.5.0 does not affect user data; the old version will
run into "check for updates failed" again on slow networks, as expected.
