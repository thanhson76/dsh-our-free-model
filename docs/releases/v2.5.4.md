# Our Free Model 2.5.4

Optimises the new desktop build, the plugin UI and the advertisements.

## What's New

- Optimised the new desktop build: improved the sponsor content's navigation entry, the light and dark themes, and display and interaction in narrow windows.
- Optimised the plugin UI: added an "Ads from sponsors" menu, so the full description, attached image, invitation code and group number can be viewed at any time.
- Optimised the ad experience: the full announcement is shown once a day by the device's local date, its body scrolls independently and the close button is always available; Esc and clicking the overlay collapse it.
- Fixed the plugin being unable to show the daily announcement inside the DSH settings dialog; collapsing the announcement keeps the settings page and returns focus to the ad menu. When another business dialog exists it still waits.
- The announcement requires no countdown, no reading the body to the end and no clicking an external link; when storage is unavailable the automatic display is skipped and the menu remains usable. The attached image is inlined in the install resources.
- The project community entry's QR code and the Chinese and English installation instructions were updated in sync.

## Installation and Update

The plugin, standalone local service and Windows desktop versions are unified at 2.5.4.

The DSH plugin uses `dsh-our-free-model-2.5.4.tgz`. For a hosted install, update the local tarball path in the profile and resolve the dependencies through the host; the npm package of the same name is not published by this repository.

For Windows desktop, fully exit the old program from the tray first, then run `Our.Free.Model_2.5.4_x64-setup.exe`. Configuration, accounts and statistics are kept; the installer is not Authenticode-signed.

After downloading, verify the files against `SHA256SUMS.txt`. The release acceptance record is provided with the install artefacts, and the actual verification scope is governed by that record.

## Rollback

After fully exiting the program, restore using the previous version's full installer or plugin tarball. Keep the existing user data; a hosted plugin also needs its corresponding dependency path restored in sync.
