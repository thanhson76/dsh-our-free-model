# Our Free Model 2.5.8

## Plugin Update

This version releases the DSH plugin, including the fixes merged into the mainline since 2.5.7:

- Update failure retry: renaming the Windows backup directory retries when it meets a temporary lock; a later update can reuse already-verified staged files, reducing repeat downloads.
- Qoder thinking levels are sorted from low to high by strength, keeping the original level IDs and default values, with unknown levels stably placed at the end.
- The local OpenAI gateway preserves `reasoning_content` / `reasoning` when receiving Chat history, including a single-space placeholder, fixing reasoning content being lost in thinking-mode tool turns; Responses encrypted reasoning items are still discarded per the existing convention.
- Chat forwarding preserves the assistant `reasoning_content` string explicitly provided by the client, including an empty string, supporting follow-up requests after tool calls.
- The plugin channel pack and standalone channel artefacts are regenerated, so the merged gateway source fixes reach the actual runtime files.
- The EAC DeepSeek Flash display name and card label gain a `1017` marker; community group 4's group number and QR code are updated.

The standalone service and desktop shell versions remain unchanged, and no new Windows desktop installer is released this time. Tag-triggered macOS community builds are handled separately by the existing CI.

## Installation

The plugin package is `dsh-our-free-model-2.5.8.tgz`. For a hosted install, update the trusted tarball path in the profile, then let the host re-resolve the dependencies; for a self-managed install, follow the existing plugin update flow.
## Verification Boundaries

Update retry, channel mounting, gateway reasoning pass-back and forwarding are verified with local stand-ins. Real upstream account calls and real Windows file-lock scenarios were not verified; the test results do not mean upstream client, region or quota restrictions have been lifted.

## Rollback

Roll back to the trusted `2.5.7` plugin tarball and re-resolve following the host installation flow. User configuration, accounts and statistics are kept.
