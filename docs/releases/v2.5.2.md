# Our Free Model 2.5.2

This version collects the fixes from the local issue audit and the reviewed PRs, and provides a pre-built DSH plugin tarball and a full Windows x64 installer.

## Fixes

- When the GitHub API is rate-limited, the upgrade check tries git refs and then the Atom feed to resolve a pinned commit, in order; a gcore manifest mirror is added. Manifest signature, per-file size and SHA-256 verification remain mandatory.
- Fixed upgrades still loading old code when the host hides its module cache, and preserved the rollback diagnostics after a startup failure. After a rollback reads a file, its original permissions are restored.
- Fixed the same announcement being notified repeatedly after the announcement fallback source's entries shrank, after recovery, or after a restart.
- The desktop build reserves a browser window for account sign-in and, when needed, asks the host to open the system browser; races in connection replacement, uninstall and slow status requests are fixed. ZCode can choose bigmodel.cn or z.ai.
- Gemini and MiniMax preserve the system prompt carried by messages; blank history and blank replies are filtered out in several adapters, while tool-result images and tool-call pairing are preserved.
- Raccoon and Loomy perform bounded account rotation on clearly insufficient quota; nothing is replayed after output exists, and the permanent credit lock is not bypassed.
- The aggregate channel sends the real model ID upstream; chains with Chinese and mixed names can still be used after saving; the chain editor shows the intersection of context, output and vision capabilities.
- The three forwarding protocols preserve the upstream error classification, HTTP status and retry hints; SSE stops reading at the terminator, and mixed JSON/SSE errors are no longer lost.
- Fixed the expected port being rewritten after a forwarding port conflict, RTK mistakenly swallowing indented source code, and similar issues.

## Features

- The plugin and standalone service support hiding a single model, or a whole group — the anonymous and Kilo groups or the EAC group; hiding does not affect starting a historical conversation request through a saved ID.
- The standalone service adds `--lan`, `--no-lan` and `--lan-port`, providing a LAN inference relay with an independent key; the management pages remain local-only.
- The DSH Tauri kernel profile can be recognised by an EAC host.
- Added a LAN default regression and fixed the dependency lock file, so a clean environment can run `npm ci --ignore-scripts`.

## Installation

DSH plugin: download this Release's `dsh-our-free-model-2.5.2.tgz` and install it following the README's local tarball flow. When a package manager owns the install directory, use `distribution: managed`, update the tarball path and let the host re-resolve the dependencies, avoiding a restart restoring the old lock file's version. This repository does not publish to the npm package of the same name.

Windows desktop: exit the old program in the tray first, then run `Our.Free.Model_2.5.2_x64-setup.exe`. Keep the original data directory; configuration, accounts and statistics are not deleted when the program is replaced.

`SHA256SUMS.txt` provides the checksums of both artefacts. The Windows installer has no Authenticode signature; the plugin upgrade manifest is signed with the established Ed25519 release key.

## Availability Notes

- The anonymous channel may still be returned `403 / LANE_LOCKED` by upstream; this version does not claim to restore upstream admission. Authorization, region, quota, certificates and upstream service status still affect real inference.
- When EAC has no body, thinking or tool progress for 60 consecutive seconds it returns `NO_PROGRESS` and does not retry automatically; heartbeat or usage frames alone do not extend the wait. Long silent computations are subject to this limit as well.
- Automated verification includes an isolated upstream; the account channels were not each verified for inference with real accounts.
- This Release provides no macOS/Linux installer that has not been verified on a real machine; macOS support PR #421 is not part of the changes integrated this time.
