# Our Free Model 2.5.6

## Plugin Update

This version releases the DSH plugin, including PR #492, already merged into main:

- A Beichen API sponsor card is shown uniformly above the Free models and EAC models pages.
- The card is smaller, with tightened spacing, icons and text layout.
- The brand copy is unified as Beichen API and OFM, and the offer text is changed to "Invite to earn a ten percent rebate".
- The "Ads from sponsors" navigation and detail route are removed, keeping the card and the "View now" link.
- Fixed old modules continuing to run under some macOS temporary-directory paths because hot-reload dependencies were not refreshed.

The standalone local service and the desktop shell are not updated with this version.

## Installation

The plugin package is `dsh-our-free-model-2.5.6.tgz`. For a hosted install, update the trusted tarball path in the profile, then let the host re-resolve the dependencies.

## Rollback

Roll back to the `2.5.5` plugin tarball and re-resolve following the host's plugin installation flow; user configuration, accounts and statistics need no migration.
