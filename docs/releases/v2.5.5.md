# Our Free Model 2.5.5

## Plugin Update

This version releases only the DSH plugin, based on the plugin changes already merged into `main`:

- Removed the community group, group number and "Copy group number" button from the sponsor notes.
- Turned off the sponsor splash advertisement that popped up automatically when the DeepSeek Harness desktop plugin started.
- Kept the sponsor page entry and the invitation code feature.

The standalone local service and the desktop shell are not updated with this version.

## Installation

The plugin package is `dsh-our-free-model-2.5.5.tgz`. For a hosted install, update the trusted tarball path in the profile, then let the host re-resolve the dependencies.

## Rollback

Roll back to the `2.5.4` plugin tarball and re-resolve following the host's plugin installation flow; user configuration, accounts and statistics need no migration.
